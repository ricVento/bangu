# 🗣️ Bangu: Laboratorio de Conlang

La palabra **bangu** proviene del Lojban y siginifica "idioma". En este repositorio escribo en lenguaje `.typ` la gramática de un idioma artificial artístico y experimental. 

### ✨ ¿Qué encontrarás aquí?

* ⚡ **Desarrollo en vivo:** Avances diarios y actualizaciones continuas sobre la lingüística del conlang.
* 🧪 **Aprendizaje sobre la marcha:** Es un espacio para mis experimentos sin horarios ni calendarios rígidos.

---

## 🗺️ Hoja de Ruta

El proyecto crece de forma **iterativa e incremental** mediante tres flujos de trabajo simultáneos que conducen a la meta definitiva: la versión **`Release`**. 

* 🔍 **Investigación y diseño:** Creación de reglas, bases de datos y plantillas en **Typst** (glosas, tablas y estilo).
* ✍️ **Redacción de borradores:** Escritura y estructuración de los capítulos dentro de la carpeta `Grammar/`.
* 👀 **Revisión y aportes:** Lectura crítica, validación de ejemplos y pulido del documento junto a la comunidad.

**¡Advertencia!** Este es un proyecto vivo; puede haber cambios continuos y radicales sobre la marcha mientras se desarrolla el conlang.

---

* 🚀 **Meta Final:** Edición definitiva lista para publicar en PDF y discutir.

---

## 📂 Contenido del repositorio

| Campo | Descripción |
| :--- | :---  |
| `Grammar/` | Carpeta con el código fuente en **Typst** (`main.typ`) que dará vida al PDF final. Dentro encontrarás más archivos `.typ` separados por capítulo. |
| `index.html` | Website donde se presenta el proyecto y eventualmente publicarán, compilándose automáticamente, los capítulos listos en PDF.  |
| `docs` | Documentación general y archivos de compilación. |
