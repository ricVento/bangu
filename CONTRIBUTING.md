# 🤝 Guía de Contribución

¡Gracias por sumarte a dar vida a esta gramática! Puedes ayudar de dos maneras:
1. 📦 Mejorando el código `.typ`
2. 💬 Haciendo sugerencias lingüísticas sobre el conlang.

Para mantener un historial limpio y fácil de leer, uso una adaptación de [Conventional Commits](https://www.conventionalcommits.org/) pensada especialmente para escribir y editar textos lingüísticos.

## ✍️ ¿Cuál será tu ayuda?

| Tipo | ¿Cuándo? |
| :--- | :--- |
| ✨ **Gramática** | Tienes ideas sobre un capítulo, nuevas reglas gramaticales, una sección o quieres dar ejemplos relevantes en tu idioma natal. |
| 🛠️ **Código** | Detectas erratas, faltas de ortografía o ejemplos incorrectos. Hay que reescribir para dar claridad o mover secciones, ajustar formato y estilos. |
| 📝 **Docs** | Corregir el `README.md`, esta guía o la página web. |
| ⚙️ **Chore** | Hacer ajustes técnicos en carpetas, plantillas o configuraciones. |

## 🏷️ Área
Menciona en qué campo lingüístico quieres hacer tu aporte:

* 🗣️ `fonética` (inventario de sonidos y fonología)
* ✒️ `ortografía` (sistemas de escritura y transcripción)
* 🧩 `morfología` (configuración general y formación de palabras)
* ⚡ `sintaxis` (tipología y estructura de oraciones)
* 📖 `glosario` (léxico básico, narraciones y listas de vocabulario)

---

### 👑 Jerarquía
Si tienes más de una idea en varias áreas a la vez, elige el tipo principal según un orden de prioridad.
